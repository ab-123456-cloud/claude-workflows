# Think Simple

Growth is the enemy — more scope, more options, more research, while the task itself sits untouched. Four steps cut back to what ships today.

## 1. Done sentence

One sentence: **"Done means: X."** X is checkable today, from the user's perspective.

- If it doesn't fit in one sentence, it is several tasks: take the one due today; the rest opens the parking list.
- If a sharpened brief is running (`execute-flow`), its done criterion is the done sentence — adopt it, don't reinvent it.

## 2. Cut

Strike until it tips: what can go without making X false? Out — one line per struck idea onto the parking list. The cut is complete when the next strike would tip X.

## 3. Build

Exactly the cut, **one solution**. Options only where the choice genuinely belongs to the user; research only if X is unreachable without it. **YAGNI** stands guard: every idea, question or tool temptation along the way costs one parking-list line and nothing more.

## 4. Ship

The moment X is true: ship, stop. The parking list goes underneath the delivery — lines in chat, not a file. It is offered; it is only started on explicit request.
